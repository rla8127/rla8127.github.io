## 배경

상담 세션은 사용자가 명시적으로 종료하지 않고 이탈하는 경우가 많습니다.
이런 세션이 정리되지 않으면 슬롯 정원을 계속 점유해 다른 사용자의 입장을 막습니다.

## 접근

두 개의 경로를 조합했습니다.

1. **실시간** — Redis Keyspace `EXPIRED` 이벤트를 구독해 TTL 만료 즉시 처리
2. **보정** — pub/sub은 구독자가 없으면 이벤트가 유실되므로, 30초 주기로 유령 점유를 스캔

두 경로가 같은 세션을 중복 처리해도 안전하도록 모든 종료 연산을 멱등하게 설계했습니다.
`UPDATE`는 `status = RUNNING` 인 행만 대상으로 하고, 타임스탬프는 `COALESCE` 로 최초값을 보존합니다.

## 배운 것

분산 환경에서 "정확히 한 번"을 보장하려 애쓰는 것보다,
**여러 번 실행돼도 결과가 같도록** 만드는 편이 훨씬 견고했습니다.
